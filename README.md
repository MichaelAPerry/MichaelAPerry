# Michael A. Perry

I teach computer networking, cybersecurity, and computer systems. I build instruments, classroom tools, and games that make technical ideas tangible.

## Instruments and firmware

- [Listen to the Broadcast](https://github.com/MichaelAPerry/ListentotheBroadcast) turns local network broadcast traffic into an ambient VST3 instrument.
- [Miku-FM](https://github.com/MichaelAPerry/MIKU-FM1) gives the M-VAVE FM-1 a singing sequencer with Japanese and English voices.
- [Keystone 280](https://github.com/MichaelAPerry/keystone280-vcv) is a set of VCV Rack modules calibrated against recordings from my own modular rack.
- [ASTRA FM-1](https://github.com/MichaelAPerry/ASTRA-FM-1) calculates planetary positions on the instrument and uses them to configure an FM patch.
- [ZOIA Patch Editor](https://github.com/MichaelAPerry/zoia-editor) opens, edits, and approximates pedal patches in a browser.

## From the classroom

- [PCAP-to-OSI](https://github.com/MichaelAPerry/pcaptoOSI) connects each highlighted byte in a packet capture to a field and an OSI layer.
- [Open School Inventory](https://github.com/MichaelAPerry/Open-School-Inventory) handles tool checkout, returns, consumables, and QR labels for school shops.
- [Beat Eve](https://github.com/MichaelAPerry/UnderstandingEncryption) is a browser lesson in key exchange and public-key infrastructure.

## Games and other experiments

- [Cave Crossword](https://github.com/MichaelAPerry/cave-crossword) makes a printable dungeon by solving a crossword inside a procedurally carved map.
- [Playloom](https://github.com/MichaelAPerry/Playloom) runs motion games with a webcam and includes a camera-free practice mode.
- [Allegheny River Atlas](https://github.com/MichaelAPerry/allegheny-river-atlas) puts launches, campsites, river miles, and other field data in an online map and a downloadable GIS dataset.
- [Screengrab Archive](https://github.com/MichaelAPerry/screengrab-archive) searches dialogue and finds the matching frame in a local video collection.

I use AI coding tools on some projects. Repositories record the tools used and the testing or measurements behind the work where that context matters.
